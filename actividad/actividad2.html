Ejercicio de explicacion de codigo

El siguiente codigo (lenguaje C), es un programa que clasifica la edad de una persona como mayor o menor de edad, y muestra un mensaje.


    int main() 
    {
        int edad;

        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);

        if (edad >= 18) 
        {
            printf("Eres mayor de edad.\n");
        }
        else 
        {
            printf("Eres menor de edad.\n");
        }
        return 0;
    }
