Ejercicio de explicacion de codigo

El siguiente codigo (lenguaje C), es un programa que clasifica la edad de una persona como mayor o menor de edad, y muestra un mensaje.


    int main() 
    {
        int edad;

        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);

        if (edad >= 18) 
        {
            printf("Eres mayor de edad.\n");
        }
        else 
        {
            printf("Eres menor de edad.\n");
        }
        return 0;
    }
Explicacion del codigo

int main( )

Es la funcion principal del programa, devuelve un valor entero.

int edad;

Se declara una variable llamada "edad" de tipo entero.

printf("¿Cuántos años tienes? ");

Imprimimos el mensaje entre comillas en la terminal

scanf("%d", &edad);

El programa espera a que el usuario ingrese un valor de tipo entero, y cuando lo recibe lo guarda en la variable "edad", el %d indica que se espera un valor entero, y el &edad es la dirección a la memoria que le indica a scanf dónde se va a guardar el valor.

if (edad >= 18)

La variable edad entra a una condicion de tipo sí/if, la condicion se expresa como, SI edad es mayor o igual a 18 años, se ejecutara ese bloque de codigo de ser cierto.

printf("Eres mayor de edad.\n");

Ya que la condición de if es verdadera, ejecuta el printf que se encuentra en su respectivo bloque de codigo, este printf imprimira en la terminal un "Eres mayor de edad." y va a imprimir igual un caracter invisible que representa un salto de linea ("\n").

else

Si la condición del if es falsa, se ejecuta el bloque de código dentro del else, es como, "okey no fue verdadera, pasemos a la siguiente condición".

printf("Eres menor de edad.\n");

Ya que entro al ese esta estructura de control, ejecuta el printf, este printf imprimira en la terminal un "Eres menor de edad." y va a imprimir igual un caracter invisible que representa un salto de linea ("\n").

return 0;

Indica que el programa ha terminado correctamente y devuelve el valor 0 al sistema operativo.
