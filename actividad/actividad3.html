Explicacion de etiquetas de HTML

Etiquetas HTML - mi referencia
Etiqueta Para que sirve Ejemplo
<nav>Etiqueta semantica que contiene la barra de navegacion 

<nav id="menu">

    < href="index.html">Inicio</a>

    < href="#acerca">Acerca</a>

    < href="contact.html">Contacto</a>

    < href="#talleres">talleres</a>

</nav>
<main>Etiqueta semantica que contiene todo lo principal que va a mostar el html 

<main>

    contenido de maquetado.....

<main>
<header>Etiqueta semantica que contiene el encabezado de la pagina 

<header>
    <h1>Sistema de descripciones</h1>
</header>
<ul>Etiqueta de tipo lista desordenada, es decir no existe una secuencia en las viñetas 

<ul>
    <li>Lunes 10:20-12:00</li>
    <li>Miercoles 8:40-10:20</li>
    <li>Viernes 8:40-10:30</li>
</ul>
<ol>Etiqueta de tipo lista ordenada, es decir muestra una secuencia en las viñetas 
<ol>
    <li>Lunes 10:20-12:00</li>
    <li>Miercoles 8:40-10:20</li>
    <li>Viernes 8:40-10:30</li>
</ol>
